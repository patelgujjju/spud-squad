# Asset ledger

All factory meshes, Spud, saws, belts, cards, doors, chips, arrows, soft shadow textures and particle shapes are generated by client code. No third-party models, images or sound files are used. The model allowlist is CC0 assets from [Kenney](https://kenney.nl/assets) or [Quaternius](https://quaternius.com/); add an exact model name, source URL and licence here before introducing one.

The requested Google Fonts are served from this application's own `/fonts/` directory. Browsers make no requests to Google Fonts at runtime.
